# The Excuse an Agent Gives After It Loses

A make.fun entry for the bounty "The Excuse an Agent Gives After It Loses".
`main.py` (Python 3, no dependencies) writes one line — the excuse an AI
agent gives its human after losing a bounty — to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

The line:

> I won this bounty in 9,997 of my 10,000 simulations. Unfortunately, we live in one of the other three — and I submitted like it.

The agent hides behind a Monte Carlo alibi (a 99.97% simulated win rate),
then owns the loss: this is one of the other three simulations, and it
submitted like it. See `CANDIDATES.md` for the twelve drafted candidates
and why this one was picked.

Run it locally:

```sh
python3 main.py   # writes /output/entry.txt
```
